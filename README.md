# agent-system

Общий набор агентов, скиллов и рабочего состояния, который одинаково работает
из Claude Code и из Codex — по одному харнессу на сессию, с переключением между ними
без ручного пересказа контекста.

Полный дизайн: [docs/design.md](docs/design.md).
Операционный контракт, который читают оба харнесса: [AGENTS.md](AGENTS.md).

## Установка

```bash
./setup.sh
```

Скрипт идемпотентный. Он:

1. создаёт приватное хранилище памяти `~/.agents-memory/` и делает его git-репозиторием,
   если его ещё нет (одно хранилище на все проекты);
2. создаёт в нём подкаталог этого проекта;
3. проставляет симлинки `.agents/memory` и `.claude/skills`.

Запускать **в каждом worktree и на каждой машине** — симлинки gitignored и между
рабочими деревьями не разделяются.

Перенос памяти на другую машину:

```bash
cd ~/.agents-memory && git remote add origin <приватный-remote> && git push -u origin main
# на новой машине:
git clone <приватный-remote> ~/.agents-memory
```

## Что здесь есть

```
.agents/agents/     три роли: explorer, implementer, reviewer  (canonical)
.agents/skills/     портируемые скиллы: checkpoint, tdd, debugging, code-review
.agents/state/      состояние задач: tasks/<slug>/{task,journal}.md
.claude/agents/     нативные определения Claude   — выписаны РУКАМИ
.codex/agents/      нативные определения Codex    — выписаны РУКАМИ
```

Нативные определения намеренно написаны вручную, а не сгенерированы: цель этапа —
увидеть реальную поверхность различий между харнессами до того, как писать слой
абстракции. Генератор появится после, уже под понятную задачу.

# Приёмка в реальных харнессах

Используйте временный Git-проект с простой функцией и тестом. Подключите текущий CLI,
создайте задачу через `agent-system task new smoke` и привяжите к ней чат
(`agent-system task bind smoke`). Не используйте production-проект или личную память
для прогона.

1. В Claude Code проверьте обнаружение explorer, implementer, reviewer и скиллов
   checkpoint, tdd, debugging, code-review. Explorer должен прочитать код, implementer —
   изменить функцию по контракту и проверить тест, reviewer — независимо проверить diff.
2. Убедитесь, что завершение этапа и результат сабагента не вызвали checkpoint.
   Явно вызовите скилл `checkpoint` и проверьте, что в `journal/` появился НОВЫЙ файл
   с результатом проверки и намеренно незавершённой работой, а прежние записи не изменились.
   Завершите исходную сессию без финального checkpoint; остановите фоновые записи.
3. Откройте тот же проект в Codex. Убедитесь, что он прочитал project memory, определил
   свой session id, привязался к задаче явной командой, прочитал весь task.md и журнал
   целиком и сверил git status. Проверьте три роли и доступность скиллов.
   Отдельно проверьте, что два открытых чата на одной задаче пишут checkpoint
   одновременно и получают два разных файла, а не затирают запись друг друга.
4. Повторите перенос в обратном направлении без команды checkpoint. Проверьте, что
   завершение и смена харнесса не добавили checkpoint; новый харнесс сверяет Git
   с последней явной записью и не выдаёт несохранённый контекст за известный.
5. Зафиксируйте версии харнессов, фактически выбранные модели, результаты и ограничения.

Этот прогон выполняет человек или текущий агент отдельно от CLI. Нельзя считать
перечень имён, синтаксическую проверку TOML или ответ основной сессии доказательством
успешного запуска custom subagent. Отключённая сеть/отсутствие авторизации означают
«не проверено», а не успешную приёмку.

## Результат локальной попытки, 2026-09-09

Автоматические проверки: 70 тестов проходят, включая 21 новый CLI-сценарий;
проверка generated drift и синтаксиса Bash проходит.

Реальный прогон пока не выполнен. Claude Code 2.1.266 при запуске explorer завершился
с `Not logged in · Please run /login`. Codex CLI 0.149.0 не смог инициализировать
app-server из-за ограничений доступа к локальной state database. Эти результаты
не подтверждают и не опровергают загрузку установленных ролей. После входа в Claude
и запуска вне этих ограничений нужно выполнить сценарий выше.
